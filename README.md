# Just Draw

Website for **Just Draw**, a simple drawing app for iPhone, iPad and iPhone Duo (iOS 27 and later): pick a color, draw, share.

Live site (once Pages is switched on): https://idrewn.github.io/justdraw-site/

- [Home](https://idrewn.github.io/justdraw-site/)
- [Privacy policy](https://idrewn.github.io/justdraw-site/privacy.html)
- [Support](https://idrewn.github.io/justdraw-site/support.html)

The site is plain HTML and CSS, published with GitHub Pages from the `main` branch. The hero mark is the same path as the app icon and
writes itself once, unless the visitor prefers reduced motion. Report problems or ideas for the app through this repository's issues.
